## Animações e Transições

### Troca de Etapas
- Fade out + translateY(20px) → Fade in + translateY(0)
- Duração: 300ms
- Easing: ease-out

### Cards de Produto (Hover)
- Border: gray → laranja
- Transform: translateY(0) → translateY(-4px)
- Box-shadow: 0 → 0 12px 32px rgba(orange, 0.15)
- Duração: 300ms

### Toggles
- Switch move: left 2px → left 26px (quando ativado)
- Background: cinza → laranja
- Duração: 300ms

### Modal
- Overlay: opacity 0 → 1 (300ms)
- Modal: scale(0.9) opacity 0 → scale(1) opacity 1 (300ms)

```
[Continuar →]
     ↓ hover

```

```
[−]  2  [+]
     ↓ click em +

```
