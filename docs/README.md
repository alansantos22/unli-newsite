## 🎓 Aprendizados do Briefing

### Decisões Estratégicas

1. **Por que anual e não mensal?**
   - Menor atrito operacional
   - Melhor margem (custos fixos anuais)
   - Cliente commit maior
   - Menos cancelamentos

2. **Por que "suporte de disponibilidade"?**
   - Evitar retrabalho infinito
   - Manter custo baixo
   - Cliente entende o escopo
   - Alterações viram upsell

3. **Por que add-on "sem reunião"?**
   - Não faz sentido reunião para 1 página
   - Processo assíncrono via formulário
   - Escala melhor
   - Cliente prefere rapidez

4. **Por que "sob proposta" para complexo?**
   - Protege margem
   - Evita subprecificação
   - Permite orçamento justo
   - Cliente entende que é diferente

### Tratamento de Objeções

| Objeção | Solução |
|---------|---------|
| "É site completo?" | FAQ: Sim, single page com tudo necessário |
| "Posso mudar sempre?" | FAQ: 1 alteração/ano, extras à parte |
| "Preciso de e-commerce?" | FAQ + Card: Projeto sob proposta |
| "Muito caro" | Comparação: ~R$1,37/dia com tudo incluso |
| "Demora muito" | Hero: 7 dias úteis (rápido para mercado) |
